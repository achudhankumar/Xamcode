Accessibility Statement

Last updated: 06 October 2026

XamCode AI is committed to ensuring digital accessibility for people with disabilities. We are continually improving the user experience for everyone and applying the relevant accessibility standards.

Our Commitment

We aim to conform to the Web Content Accessibility Guidelines (WCAG) 2.2 at Level AA. This is an international standard published by the World Wide Web Consortium (W3C).

Technical Accessibility

  • All meaningful images have descriptive alt text
  • Every interactive element is keyboard reachable with visible focus indicator
  • Focus order is logical and intuitive
  • Forms have clear labels, instructions, and accessible error messages
  • Color is never the only indicator of state or information
  • Text can be resized up to 200% without loss of functionality
  • Headings follow a logical hierarchy
  • Buttons are coded as buttons; links as links
  • Animations respect the prefers-reduced-motion setting
